# Contributing

VORQA is in the repository-foundation phase. Open an issue before changing security gates, the state model or platform integrations. Use focused feature branches and reviewed pull requests.

Every change should explain its scope, affected platforms, security implications, tests actually run, and remaining limitations. Never turn an agent's PASS assertion into release proof. Review third-party references for redistribution rights, and avoid committing secrets, local paths or runtime state.

No project-wide redistribution license has been selected. Do not assume public availability grants a license to reuse all source materials.
